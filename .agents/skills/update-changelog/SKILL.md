description: Обновление файла CHANGELOG.md с учетом изменений текущей ветки по сравнению с основной
---

## Шаги выполнения

### 1. Анализ структуры CHANGELOG.md

- Изучить формат дат, стиль записей и порядок разделов

### 2. Получение diff с основной веткой

```bash
git diff main > tmp/changelog.diff
```

- Проанализировать diff для выявления ключевых изменений

### 3. Обновление CHANGELOG.md

- Добавить подзаголовок с текущей датой (YYYY-MM-DD)
- Описать изменения в стиле проекта:
  - Каждый пункт - одна фраза
  - Без деталей реализации
- Соблюдать обратную хронологическую сортировку

### 4. Удаление временного diff файла

```bash
rm tmp/changelog.diff
```

## Пример

```markdown
## 2025-08-21

- Исправлена проблема определения времени выдержки в приложении галереи, приводившая к ошибке 500.
- Исправлена проблема при генерации значений объектов фабриками в тестах, когда нарушалось ограничение уникальности полей.
```

## Рекомендации

- Убедиться, что ветка актуальна относительно основной
- Проверить форматирование markdown
- Следовать стилю проекта
