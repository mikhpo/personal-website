## Предназначение

Поддержание единой типографики в текстовых файлах репозитория: документация, комментарии, докстринги, строки кода. Скрипт ищет запрещенные символы и заменяет их в файле напрямую; измененные файлы сообщаются пользователю.

## Правила замен

- длинное тире (U+2014) -> дефис "-"
- стрелка (U+2192) -> "->"
- кавычки-ёлочки (U+00AB и U+00BB) -> прямые кавычки '"'

Обрабатываются только файлы, декодируемые как UTF-8; остальные пропускаются без изменений.

## Использование

Скрипт входит в скилл: `scripts/fix_typography.py`.

```bash
# Без аргументов - все файлы, отслеживаемые git (запуск из каталога скилла)
python3 scripts/fix_typography.py

# С аргументами - только переданные файлы
python3 scripts/fix_typography.py README.md docs/guide.md
```

Код возврата: 0 - замен не было, 1 - выполнена хотя бы одна замена (измененные файлы добавляются в индекс и прогон повторяется).
